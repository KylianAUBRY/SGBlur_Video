# Code of conduct

SGBlur-Video adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. By participating in this project (issues, pull
requests, discussions, any other project space), you agree to follow it.

## In short

Be welcoming, respectful and constructive. Harassment, insults, personal or
political attacks, and publishing other people's private information are not
accepted. In this project specifically, that includes sharing images or videos
in which people can be identified.

## Reporting

Report unacceptable behaviour privately to a maintainer, using the contact
details shown on their GitHub profile. Reports are handled confidentially and
the reporter's identity is protected. (v1 is a hackathon project; a dedicated
private reporting channel is planned for v2, see [SECURITY.md](SECURITY.md).)

## Enforcement

Maintainers apply the enforcement guidelines of the Contributor Covenant 2.1
(correction, warning, temporary ban, permanent ban), proportionate to the
behaviour.
